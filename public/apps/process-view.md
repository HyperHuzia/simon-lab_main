# ProcessView

ProcessView is layer 1 of the Simon Lab stack: a web P&ID with an embedded physics simulation for chemical plant design and control.

## Canonical page
- https://simon-lab.org/apps/processview/ (Polish: https://simon-lab.org/pl/apps/processview/, German: https://simon-lab.org/de/apps/processview/)

## What it does
- Builds the P&ID element by element: equipment, lines, valves and instruments, each carrying its full selection
- Keeps materials, pipelines and instruments in registers generated from the same model
- Runs a dynamic simulation of the process, so it is tested before anything is bought
- Runs ready-made control programs on an emulated PLC
- Reads the specification from CapacityIndex (layer 0) and feeds MechGraph and IonGrid (layer 2)
