# Google Ads: a search campaign in Polish

Generated by `npm run profiles` from `src/content/profiles/` and `src/data/profiles.ts`: change the texts there, not here. A text in a box is ready to paste; beside it, its length and the platform’s limit.

- Network: Google Search only (no Display Network, no search partners); location Poland (people in it), language Polish.
- Bidding: manual CPC, a default per ad group and a bid of its own where a keyword has one; keywords in phrase and exact match only; the schedule and the budget are set in the account, not here.
- No Google tag on the site, no conversion tracking: the ads’ addresses carry `?ref=google-ads`, and "Write to us" adds the source to the email’s subject.
- Final URL of every ad: https://simon-lab.org/pl/services/?ref=google-ads
